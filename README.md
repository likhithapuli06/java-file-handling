# Task 4 – File Handling & Basic Git Usage

## Overview

This project demonstrates basic file handling in Java using `FileWriter` and `FileReader`.

## Features

* Write student data to a text file
* Read data from a text file
* Handle file-related errors using try-catch
* Manage the project using Git and GitHub

## Technologies Used

* Java
* FileReader
* FileWriter
* Git
* GitHub

## How to Run

Compile the Java program:

```bash
javac FileHandlingDemo.java
```

Run the program:

```bash
java FileHandlingDemo
```

The program creates a `students.txt` file, writes student information to it, and then reads and displays the stored information.

## Git Commands Used

```bash
git init
git add .
git commit -m "Add Java file handling project"
git branch -M main
git remote add origin <your-github-repository-url>
git push -u origin main
```

## Output

The program displays a success message after writing the data and then displays the contents read from the text file.
